# 에셋 후처리 스크립트

AI 로 생성한 스탠딩을 게임에 넣기 전에 손보는 도구다. 생성 결과가
그대로 쓸 수 있는 상태로 나오지 않기 때문에 남겨 둔다.

의존: `pillow`, `numpy`, `scipy`, 나눔 폰트(`apt install fonts-nanum`)

## remove_hair_gaps.py

머리카락에 둘러싸여 남은 흰 배경 조각을 지운다.

배경 제거를 테두리 flood fill 로만 하면, 옆머리와 어깨 사이처럼
머리카락으로 둘러싸인 틈은 테두리와 이어져 있지 않아 흰색이 남는다.

판정에 두 기준을 **함께** 쓴다.

1. 조각 바깥 한 겹이 대부분 어두운가 → 머리카락에 둘러싸였다
2. 실루엣 바깥까지 거리가 70px 미만인가 → 가장자리의 얇은 틈이다

드로우코드도 1번은 만족한다(어두운 외곽선과 초록 글자에 닿아 있다).
하지만 몸 한가운데라 2번에서 걸러진다. **조건 하나만 쓰면 드로우코드가
지워진다.**

| | 테두리 어두움 | 실루엣까지 거리 |
| --- | --- | --- |
| 머리 사이 틈 | 78% | 4px |
| 드로우코드 | 64~66% | 101~195px |
| 티셔츠 | 29~49% | 136~154px |

## relabel_name_patch.py

가슴 명찰의 글자를 다시 쓴다.

이미지 생성 모델이 한글을 자주 틀리게 그린다. 실제로 `판교하` 를
요청했는데 `만고하` 로 나왔다. 스프라이트를 다시 생성하면 얼굴이
미세하게 달라지므로, 명찰 안쪽만 덮어쓴다.

명찰은 가슴 높이의 밝은 가로 직사각형으로 찾고, 위 테두리 기울기를
재서 같은 각도로 글자를 얹는다. 테두리와 알파(실루엣)는 건드리지
않는다.
