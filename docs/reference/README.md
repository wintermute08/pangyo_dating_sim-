# 참고 자료

게임 제작에 전달된 원본 자료를 루트에서 분리해 보관한다. 런타임에서는 이 폴더의 파일을 직접 사용하지 않는다.

| 파일 | 용도 |
| --- | --- |
| `ui-direction.png` | 전체 UI 분위기와 색감 참고 |
| `title-logo-reference.png` | 전달받은 타이틀 참고 이미지; 현재 로고 생성 입력에는 사용하지 않음 |
| `title-logo-generated-v1.png` | 참고 이미지와 유사도가 높아 교체한 첫 생성안 |
| `heroine-closeup-reference.png` | 히로인 얼굴·화풍 참고 |
| `school-*-reference.*` | 판교고 건물 참고 사진 |
| `concept-document.pdf` | 초기 전체 제작 기획서; 최종본에서는 참고 비중을 낮춤 |
| `ui-mockup-handoff.zip` | 디자인 도구 원본 핸드오프; 150 MB라 Git 추적 제외 |

최종 게임 에셋은 `assets/`, 실제 UI 구현은 `index.html`, `css/`, `js/`에 있다.
