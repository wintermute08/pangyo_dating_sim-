# 판교고 미연시 — 봄은, 열 걸음 늦게 온다

판교고를 배경으로 한 10분 분량의 브라우저 비주얼노벨이다. 별도 빌드나 패키지 설치 없이 정적 파일만으로 실행된다.

## 실행

프로젝트 루트에서 정적 서버를 연다.

```bash
python3 -m http.server 8000
```

그다음 `http://localhost:8000`에 접속한다. 로컬 저장·불러오기 기능 때문에 `index.html`을 직접 여는 것보다 정적 서버 사용을 권장한다.

## 구현된 기능

- 6개 장면과 선택지 4회, 엔딩 3종
- 이름 입력과 한국어 호격 조사 처리
- 자동 저장, 수동 저장 6슬롯, 불러오기
- 지난 대화 로그와 CG/엔딩 감상 모드
- 텍스트 속도·자동 진행·음악·효과음·움직임 설정
- 키보드 진행(Enter/Space), 숫자 선택지, 전체 화면
- Web Audio 기반의 잔잔한 배경음과 효과음
- 데스크톱·태블릿·모바일 반응형 UI

## 프로젝트 구조

```text
assets/            실제 게임 배경, 캐릭터, CG, 생성형 타이틀 로고
css/game.css       화면 디자인과 반응형 레이아웃
js/game.js         비주얼노벨 엔진, 저장, 설정, 오디오
script/story.js    본편 시나리오 데이터
script/ending.js   엔딩 데이터
docs/reference/    전달받은 기획·사진·UI 참고 자료
index.html         실행 진입점
```

## 기획 정리 기준

최종본은 최신 UI 목업과 사용자의 직접 지시를 우선했다. 초기 `판교고 10분 미연시 전체 제작 기획서`에서는 6장면 구조, 키링 찾기, 학교에 대한 질문만 남겼고 캐릭터 이름과 감정선은 새 자료에 맞춰 다시 정리했다. 히로인 이름은 **판교하**다.

## 에셋 메모

현재 타이틀 로고 `assets/title-logo-v2.png`는 기존 참고 이미지를 생성 입력에 사용하지 않고, 노트 선·열 걸음·꽃잎을 모티프로 새로 제작했다. 참고 이미지와 닮았던 첫 생성안은 비교 기록을 위해 `docs/reference/title-logo-generated-v1.png`로 옮겼다. 나머지 게임 이미지는 UI 핸드오프에 포함된 동일 화풍 에셋 중 완성도가 높은 파일만 선별했다.

외부 공개 전에는 학교명·교표·참고 사진과 AI 생성 이미지의 사용 권한을 별도로 확인해야 한다.
